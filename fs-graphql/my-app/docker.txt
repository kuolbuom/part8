Step 9: Understand the GraphQL URL

Because Apollo Client sends GraphQL requests from your browser, 127.0.0.1:4000 points to your computer's port 4000. Our Compose file publishes the backend's port 4000, so this URL can work without changing it.
The distinction is:
- Browser → backend: 127.0.0.1:4000/graphql can work because port 4000 is published.
- Container → container: use the Compose service name, such as http://backend:4000/graphql.
