# Stage 1: Build the frontend
FROM node:24 AS build

COPY library-frontend/package*.json ./

RUN npm ci

RUN npm run build

# Stage 2: Serve the production files

Save the file as Dockerfile, making sure Notepad does not save it as Dockerfile.txt.
Step 2: Understand each part
Stage 1 — Build with Node.js
- FROM node:24 AS build gives us Node.js and names this stage build.
- WORKDIR sets the working directory inside the container.
- COPY brings the frontend's package files into the image.
- RUN npm ci installs the exact dependencies recorded in the lockfile.
- COPY library-frontend/ ./ copies your React source code.
- RUN npm run build creates the production files in dist/.
Stage 2 — Serve with Nginx
- FROM nginx:1.29-alpine starts a separate, lightweight Nginx image.
- COPY --from=build ... copies only the built dist files from Stage 1.
This is a multi-stage build. The final image serves the built frontend; it does not need Node.js or the original source files.
